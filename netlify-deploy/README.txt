ROBLOKVOTE - VERSION NETLIFY DROP
=====================================

INSTRUCCIONES PARA SUBIR:
1. Ve a https://app.netlify.com/drop
2. Arrastra esta carpeta completa a la pagina
3. Listo! Copia el link generado

IMPORTANTE:
- Esta version es SOLO el modo individual
- El modo multijugador necesita servidor Node.js
- Para multijugador usa: Railway.app o Render.com (gratis)

ARCHIVOS:
- index.html: Pagina principal
- app.js: Logica de votacion
- data.js: Datos de 150 personajes
- images/: Fotos de los personajes

CONTROLES:
- Desliza a la derecha o tecla D = SI
- Desliza a la izquierda o tecla A = NO

DISFRUTA!
