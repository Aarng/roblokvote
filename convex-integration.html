📋 Instrucciones de configuración

  1. Ve a convex.dev y crea una cuenta
  2. Crea un nuevo proyecto llamado "proyectopiece"
  3. En el dashboard de Convex, ve a Settings
  4. Copia la URL de tu proyecto (empieza con https://)
  5. Crea un archivo .env en la raíz con:
    VITE_CONVEX_URL=tu-url-de-convex
  6. Instala el CLI de Convex:
    npm install -g convex
  7. En la terminal, corre:
    convex dev

Los archivos de schema y funciones ya están creados en la carpeta /convex
